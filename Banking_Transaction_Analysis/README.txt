BANKING TRANSACTION ANALYSIS SYSTEM

FASTEST WAY TO RUN LOCALLY:
1. Install Python 3 if needed.
2. Open a terminal in this folder.
3. Run: pip install -r requirements.txt
4. Run: streamlit run app.py
5. Your browser should open the dashboard automatically.

TO OPEN IN AN ONLINE BROWSER:
1. Go to https://replit.com/ and sign in.
2. Create a new Python project (or import/upload these files if the option is available).
3. Upload app.py and requirements.txt.
4. In the Shell/Console, install dependencies: pip install -r requirements.txt
5. Run: streamlit run app.py --server.address 0.0.0.0 --server.port 3000
6. If Replit offers a web preview/port link, open it. Online hosting steps and availability may vary.

FEATURES:
- Sample transaction dataset
- Credits, debits and closing balance summary
- Transaction table with filters/search
- Spending category and credit/debit charts
- Monthly analysis
- Configurable large-transaction review flag
- CSV upload and download

IMPORTANT: This is an educational demo, not a real banking app and not connected to a bank. Do not upload sensitive personal banking data.
